✅ What Works: Key Learnings

Social Proof for Dedektifler = 🚀

From 12 tests, 89% win rate

💡 Showing "X people viewed this profile" increases curiosity-driven actions by 18-24%

Authority messaging for Mağdurlar

From 9 tests, 82% win rate

💡 "Trusted by 100M+ users" and security badges build trust faster than feature lists

Value reminders work for Pasifler

From 7 tests, 71% win rate

💡 Weekly "You blocked 12 spam calls" notifications re-engage dormant users

Onboarding: Show value FIRST

Multiple tests, consistent pattern

💡 Users who see their own profile/tags in first session are 3x more likely to convert to premium

❌ What Doesn't Work: Avoid These

Aggressive scarcity backfires

Trial 7d→3d test

⚠️ Reducing trial from 7 to 3 days increased churn by 8%. Users need time to reach Aha Moment.

Gamification fails for Pasifler

Points/badges test

⚠️ Pasifler want utility, not engagement. Points systems had zero impact on this segment.

Feature-heavy messaging loses

Multiple messaging tests

⚠️ Listing features ("50M database!") performs worse than benefit-focused copy ("Know who's calling")

Generic "All Users" tests underperform

Pattern across 15+ tests

⚠️ Segment-specific tests average 67% win rate vs. 42% for generic tests

📖 Segment Playbooks: Best Practices

🕵️ Dedektifler Playbook

PRIMARY MOTIVATION

Curiosity + FOMO ("Who viewed me?")

WINNING TACTICS

  • Social proof ("500 viewing now")
  • Partial information reveal
  • Authority signals
  • Real-time notifications

AVOID

  • Aggressive scarcity
  • Long paywalls

🛡️ Mağdurlar Playbook

PRIMARY MOTIVATION

Safety + Peace of mind

WINNING TACTICS

  • Authority messaging
  • Trust signals (badges, stats)
  • Value reminders ("You're protected")
  • Educational content

AVOID

  • Fear-based marketing
  • Complex features

😴 Pasifler Playbook

PRIMARY MOTIVATION

Set & forget utility

WINNING TACTICS

  • Reciprocity ("We protected you")
  • Passive value delivery
  • Low-frequency reminders
  • Automation features

AVOID

  • Gamification
  • High engagement tactics
